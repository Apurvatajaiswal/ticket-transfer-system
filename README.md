# ticket-transfer-system
A FastAPI based ticket transfer system where users can upload, negotiate, search and claim information about available train tickets.
# PostChart 🚆

A full-stack ticket transfer platform where users can search and exchange train tickets.

## Features
- Search tickets
- View available trains
- Payment integration (Razorpay)
- FastAPI backend
- Responsive UI

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: FastAPI
- Database: SQLite
- Payment: Razorpay
- Deployment: Render + Vercel
